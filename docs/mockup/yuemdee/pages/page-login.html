เข้าสู่ระบบด้วย UBU Single Sign-On

ยืนยันตัวตนผ่านบริการกลางของมหาวิทยาลัยอุบลราชธานี (@ubu.ac.th)
(จำลอง: คลิกเลือกบัญชีทดสอบด้านล่าง)

เลือกบัญชีทดสอบ (UBU SSO)

ทดสอบกรณีปฏิเสธการเข้าถึง (Exception Flow)

🛠️

เข้าสู่ระบบผู้ดูแลระบบ (Admin)

ใช้บัญชี Local Database บัญชีเดียวกับ Django Admin Backend (/admin/)
ไม่ต้องใช้บัญชีอีเมล UBU SSO

💡
Django Superuser Authentication แอดมินสร้างบัญชีผ่านคำสั่ง createsuperuser เมื่อล็อกอินจะได้รับ Session ที่เข้าใช้งานได้ทั้งหน้าบ้าน (Admin Panel) และหลังบ้าน Django Admin
