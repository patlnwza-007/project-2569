# Field Mapping: `page-item-status-change.html` (เปลี่ยนสถานะครุภัณฑ์/วัสดุคงทน)

> **หน้าจอ:** ปรับปรุงสถานะความพร้อมใช้งานของพัสดุ (พร้อมใช้ / ส่งซ่อม / ปลดระวาง)  
> **ไฟล์ต้นทาง:** `pages/page-item-status-change.html`  
> **ผู้ใช้งาน:** 👷 เจ้าหน้าที่ (Staff)  
> **Use Case:** UC-23  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **ข้อมูลสิ่งของที่กำลังเปลี่ยนสถานะ** | | | |
| รูปภาพและชื่อสิ่งของ | Image / Text | `ITEM.image`, `ITEM.name` | ดึงข้อมูลสิ่งของเดิม |
| รหัสประจำชิ้น (ครุภัณฑ์) | Text (Badge) | `EQUIPMENT.asset_tag` | รหัสเฉพาะชิ้น |
| สถานะปัจจุบัน | Badge | `ITEM.base_status`, `EQUIPMENT.status` | สถานะเดิมในระบบ |
| **แบบฟอร์มการเปลี่ยนสถานะ** | | | |
| สถานะใหม่ที่ต้องการเปลี่ยน | Select | `EQUIPMENT.status` หรือ `ITEM.base_status` | - สำหรับครุภัณฑ์: `AVAILABLE`, `DAMAGED`, `MAINTENANCE`, `RETIRED`<br>- สำหรับสิ่งของทั่วไป: `AVAILABLE`, `DAMAGED`, `INACTIVE`, `RETIRED` |
| หมายเหตุสภาพ / เหตุผล | Input (Textarea) | `EQUIPMENT.note` | บันทึกรายละเอียดเพิ่มเติม เช่น อาการเสีย สาเหตุการส่งซ่อม |
| วันที่บันทึกการเปลี่ยนสถานะ | Datetime (Auto) | บันทึกการแก้ไขแถว | อัปเดตข้อมูลลงในตารางที่เกี่ยวข้อง |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ไม่มีฟิลด์นอกเหนือจากที่ระบุ

---

- `ITEM`
