# Field Mapping: `page-request-form.html` (ยืนยันส่งคำขอยืม)

> **หน้าจอ:** หน้าตรวจสอบรายการขั้นสุดท้าย แนบรูปถ่ายสภาพเดิม และยืนยันส่งคำขอยืมหน้าเคาน์เตอร์  
> **ไฟล์ต้นทาง:** `pages/page-request-form.html`  
> **ผู้ใช้งาน:** 🎓 นักศึกษา (Student)  
> **Use Case:** UC-06  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **การตรวจสอบสิทธิ์และข้อมูลผู้ยืมก่อนส่ง** | | | |
| ตรวจสอบสถานะระงับสิทธิ์ | Logic Check | `USER.blocked`, `USER.block_reason` | หากถูกบล็อก ระบบไม่อนุญาตให้ส่งคำขอ |
| ตรวจสอบเบอร์โทรศัพท์ติดต่อ | Logic Check | `STUDENT.phone` | ต้องมีเบอร์โทรศัพท์ในระบบ หากไม่มีจะแจ้งให้กรอกที่หน้าโปรไฟล์ |
| **รายการสิ่งของในคำขอ** | | | |
| ชื่อและประเภทสิ่งของ | Text / Badge | `ITEM.name`, `ITEM.item_type`, `ITEM.unit` | รายการที่หยิบมาจากตะกร้า |
| รหัสประจำชิ้น (ครุภัณฑ์) | Text (Badge) | `EQUIPMENT.asset_tag` | รหัส Asset Tag ชิ้นที่เลือก |
| จำนวนที่ขอยืม | Text | `BORROW_ITEM.qty` | จำนวนของแต่ละรายการ |
| อัปโหลดรูปถ่ายสภาพของก่อนยืม (ถ้ามี) | Input (File) | `BORROW_ITEM.initial_photo` | แนบรูปหลักฐานสภาพของจริงหน้าเคาน์เตอร์ |
| **เงื่อนไขคำขอยืม** | | | |
| ตัวเลือกขอยืมระยะยาวกรณีพิเศษ | Checkbox | `BORROW_REQUEST.is_special` | ติ๊กเมื่อขอยืมทำโครงงาน/วิจัยระยะยาว |
| วันที่ขอส่งคืนกรณีพิเศษ | Input (Date) | `BORROW_REQUEST.custom_due_date` | ระบุวันที่ต้องการส่งคืนกรณีขอยืมพิเศษ |
| **การบันทึกคำขอเมื่อกดยืนยัน** | | | |
| ผู้ยืม | FK (Hidden) | `BORROW_REQUEST.user_id` | บันทึกรหัสผู้ใช้งานปัจจุบัน (`STUDENT.user_id`) |
| วันที่เริ่มใช้งาน | Date (Auto) | `BORROW_REQUEST.use_date` | บันทึกวันที่ปัจจุบันที่ทำรายการหน้าเคาน์เตอร์ |
| สถานะคำขอเริ่มต้น | Status (Auto) | `BORROW_REQUEST.status` | ตั้งเป็น `'PENDING'` (รอเจ้าหน้าที่ตรวจของ) |
| วันเวลาที่ส่งคำขอ | Datetime (Auto) | `BORROW_REQUEST.created_at` | บันทึกเวลาที่ส่งคำขอ (`NOW()`) |
| รายการสิ่งของในคำขอ | Table Record | `BORROW_ITEM` | บันทึกแถวรายการยืม: `borrow_request_id`, `item_id`, `qty`, `initial_photo` |
| ล้างตะกร้าหลังส่งคำขอ | Action | ลบ `CART_ITEM` | เคลียร์รายการในตะกร้าที่ส่งคำขอแล้วออก |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ป้ายนับถอยหลัง / คำเตือน "นำของมาวางหน้าเคาน์เตอร์ก่อนกดยืนยัน": ข้อความแนะนำการปฏิบัติงาน (Static Instruction)

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `BORROW_REQUEST`
- `BORROW_ITEM`
- `USER`
- `STUDENT`
- `ITEM`
- `EQUIPMENT`
- `CART_ITEM`
