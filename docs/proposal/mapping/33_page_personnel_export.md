# Field Mapping: `page-personnel-export.html` (ส่งออกรายชื่อบุคลากร CSV)

> **หน้าจอ:** ส่งออกไฟล์ CSV รายชื่อบุคลากรทั้งหมดที่เคยล็อกอิน และผู้ที่ได้รับสิทธิ์ Role Override ล่วงหน้า  
> **ไฟล์ต้นทาง:** `pages/page-personnel-export.html`  
> **ผู้ใช้งาน:** 👑 ผู้ดูแลระบบ (Admin)  
> **Use Case:** UC-34  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / ข้อมูลในไฟล์ CSV ที่ส่งออก | ประเภท UI / CSV Header | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| ปุ่มส่งออก `[ 📥 ดาวน์โหลด CSV ]` | Button | คำสั่ง Export CSV | ประมวลผลและสร้างไฟล์ CSV จากฐานข้อมูล |
| **โครงสร้างคอลัมน์ภายในไฟล์ CSV** | | | |
| ชื่อ - นามสกุล | คอลัมน์ `name` | `USER.name` | ดึงชื่อบุคลากร |
| อีเมลมหาวิทยาลัย | คอลัมน์ `email` | `USER.email` | อีเมล @ubu.ac.th |
| สถานะการแต่งตั้งพิเศษ | คอลัมน์ `is_override` | `STAFF.is_override` | `true` (Role Override) หรือ `false` (SSO Staff) |
| เหตุผลการแต่งตั้ง | คอลัมน์ `override_reason` | `STAFF.override_reason` | เหตุผลการกำหนดบทบาท |
| วันเวลาที่แต่งตั้งสิทธิ์ | คอลัมน์ `assigned_at` | `STAFF.assigned_at` | เวลาที่ได้รับการแต่งตั้ง |
| ผู้แต่งตั้งสิทธิ์ | คอลัมน์ `assigned_by` | `STAFF.assigned_by -> ADMIN.name` | ชื่อแอดมินผู้แต่งตั้ง |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ไม่มีระบบ Whitelist (ไม่มีตาราง Whitelist ตามข้อกำหนดของระบบ) — รายชื่อในไฟล์ดึงมาจากบันทึกผู้ใช้จริงใน `USER` ที่มีแถวคู่ใน `STAFF` เท่านั้น

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `USER`
- `STAFF`
- `ADMIN`
