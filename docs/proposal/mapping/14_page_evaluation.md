# Field Mapping: `page-evaluation.html` (ประเมินความพึงพอใจและรีวิว)

> **หน้าจอ:** ฟอร์มประเมินความพึงพอใจ ให้คะแนนดาว และเขียนรีวิวสภาพการใช้งานจริงรายชิ้น  
> **ไฟล์ต้นทาง:** `pages/page-evaluation.html`  
> **ผู้ใช้งาน:** 🎓 นักศึกษา (Student)  
> **Use Case:** UC-14  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **ข้อมูลสิ่งของที่กำลังประเมิน** | | | |
| รูปภาพสิ่งของ | Image | `ITEM.image` | ดึงผ่าน `BORROW_ITEM.item_id` |
| ชื่อสิ่งของ | Text | `ITEM.name` | ชื่อสิ่งของที่เคยยืม |
| รหัสประจำชิ้น (ครุภัณฑ์) | Text (Badge) | `EQUIPMENT.asset_tag` | รหัส Asset Tag ชิ้นที่ยืม |
| รายการยืมอ้างอิง | FK (Hidden) | `REVIEW.borrow_item_id` | ผูก 1 รายการยืม ต่อ 1 รีวิว (1-to-1) เพื่อความเป็น 3NF |
| **แบบฟอร์มการประเมิน** | | | |
| คะแนนดาวความพึงพอใจ (1–5 ดาว) | Star Rating | `REVIEW.rating` | บันทึกคะแนนตัวเลขจำนวนเต็ม 1 ถึง 5 |
| ความคิดเห็นรีวิวสภาพการใช้งานจริง | Input (Textarea) | `REVIEW.comment` | ข้อความอธิบายสภาพพัสดุ ปัญหาที่พบ หรือความประทับใจ |
| วันเวลาที่ส่งรีวิว | Datetime (Auto) | `REVIEW.created_at` | บันทึกเวลาที่ส่งรีวิว (`NOW()`) |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ข้อมูลชื่อผู้รีวิว และชื่อสิ่งของที่รีวิว ไม่ได้เก็บซ้ำในตาราง `REVIEW` เพราะสามารถสืบหาผ่าน `REVIEW -> BORROW_ITEM -> ITEM` และ `BORROW_REQUEST.user_id` ได้โดยตรงตามหลัก 3NF

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `REVIEW`
- `BORROW_ITEM`
- `ITEM`
- `EQUIPMENT`
- `BORROW_REQUEST`
- `USER`
