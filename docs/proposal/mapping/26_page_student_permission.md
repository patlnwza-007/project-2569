# Field Mapping: `page-student-permission.html` (จัดการสิทธิ์การยืมของนักศึกษา)

> **หน้าจอ:** ตรวจสอบประวัติและสั่งระงับสิทธิ์ (Block) หรือปลดบล็อกการยืมของนักศึกษา  
> **ไฟล์ต้นทาง:** `pages/page-student-permission.html`  
> **ผู้ใช้งาน:** 👷 เจ้าหน้าที่ (Staff), 👑 ผู้ดูแลระบบ (Admin)  
> **Use Case:** UC-27  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **ข้อมูลนักศึกษา** | | | |
| ชื่อ-นามสกุล | Text | `USER.name` | ดึงชื่อนักศึกษา |
| รหัสนักศึกษา (11 หลัก) | Text | `STUDENT.student_id` | รหัสนักศึกษา |
| อีเมลมหาวิทยาลัย | Text | `USER.email` | อีเมล @ubu.ac.th |
| เบอร์โทรศัพท์ | Text | `STUDENT.phone` | เบอร์โทรศัพท์ 10 หลัก |
| สถานะสิทธิ์การยืมปัจจุบัน | Badge | `USER.blocked` | `true` (ถูกระงับสิทธิ์) หรือ `false` (ปกติ) |
| เหตุผลการระงับสิทธิ์ปัจจุบัน | Text | `USER.block_reason` | แสดงเหตุผลเดิม (ถ้ามี) |
| ผู้สั่งระงับสิทธิ์ล่าสุด | Text | `USER.blocked_by_staff` หรือ `USER.blocked_by_admin` | แสดงชื่อเจ้าหน้าที่หรือแอดมินผู้สั่งระงับสิทธิ์ |
| **ฟอร์มดำเนินการสั่งระงับสิทธิ์ / ปลดบล็อก** | | | |
| สวิตช์ระงับสิทธิ์ (Block Switch) | Toggle / Checkbox | `USER.blocked` | สลับเป็น `true` (ระงับสิทธิ์) หรือ `false` (ปลดบล็อก) |
| เหตุผลการระงับสิทธิ์ | Input (Textarea) | `USER.block_reason` | บังคับกรอกเมื่อทำการระงับสิทธิ์ เช่น ค้างส่งคืนพัสดุเกินกำหนด |
| ผู้สั่งระงับสิทธิ์ (เมื่อกดบันทึก) | FK (Auto) | `USER.blocked_by_staff` หรือ `USER.blocked_by_admin` | บันทึก ID ของเจ้าหน้าที่ (`STAFF.user_id`) หรือแอดมิน (`ADMIN.id`) ที่ทำรายการ |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ไม่มีฟิลด์นอกเหนือจากที่ระบุ

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `USER`
- `STUDENT`
- `STAFF`
- `ADMIN`
