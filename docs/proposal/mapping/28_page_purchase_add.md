# Field Mapping: `page-purchase-add.html` (รายการจัดซื้อ)

> **หน้าจอ:** ติดตามรายการจัดซื้อพัสดุ และเพิ่มรายการจัดซื้อใหม่ด้วยตนเอง  
> **ไฟล์ต้นทาง:** `pages/page-purchase-add.html`  
> **ผู้ใช้งาน:** 👷 เจ้าหน้าที่ (Staff)  
> **Use Case:** UC-29  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **ฟอร์มเพิ่มรายการจัดซื้อด้วยตนเอง** | | | |
| ชื่อสิ่งของที่จะจัดซื้อ | Input (Text) | `PURCHASE_PLAN.name` | ระบุชื่อพัสดุที่ต้องการจัดซื้อ |
| รายละเอียดและแผนการจัดซื้อ | Input (Textarea) | `PURCHASE_PLAN.detail` | ระบุรายละเอียดงบประมาณ หรือสเปก |
| ผู้บันทึกรายการจัดซื้อ | FK (Auto) | `PURCHASE_PLAN.created_by` | บันทึกรหัสเจ้าหน้าที่ (`STAFF.user_id`) |
| วันเวลาที่บันทึก | Datetime (Auto) | `PURCHASE_PLAN.created_at` | บันทึกเวลาที่สร้างแผน (`NOW()`) |
| **ตารางรายการแผนการจัดซื้อทั้งหมด** | | | |
| ชื่อสิ่งของที่จะจัดซื้อ | Text | `PURCHASE_PLAN.name` | ชื่อพัสดุในแผน |
| รายละเอียดการจัดซื้อ | Text | `PURCHASE_PLAN.detail` | รายละเอียด |
| ที่มาของรายการ (จากคำเสนอแนะ vs เพิ่มเอง) | Badge / Text | `PURCHASE_PLAN.suggestion_id` | หากมีค่า แสดงชื่อข้อเสนอแนะเดิม หากเป็น `NULL` แสดงว่าเจ้าหน้าที่เพิ่มเอง |
| เจ้าหน้าที่ผู้บันทึก | Text | `USER.name` | ดึงชื่อผู้บันทึกผ่าน `PURCHASE_PLAN.created_by -> STAFF.user_id -> USER.name` |
| วันที่บันทึกรายการ | Datetime | `PURCHASE_PLAN.created_at` | เวลาที่สร้างรายการ |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ไม่มีฟิลด์นอกเหนือจากที่ระบุ

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `PURCHASE_PLAN`
- `SUGGESTION`
- `STAFF`
- `USER`
