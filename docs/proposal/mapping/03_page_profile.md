# Field Mapping: `page-profile.html` (โปรไฟล์ส่วนตัว)

> **หน้าจอ:** หน้าดูและแก้ไขข้อมูลส่วนตัวของผู้ใช้งาน  
> **ไฟล์ต้นทาง:** `pages/page-profile.html`  
> **ผู้ใช้งาน:** 🎓 นักศึกษา (Student), 👷 เจ้าหน้าที่ (Staff)  
> **Use Case:** UC-13  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| รหัสนักศึกษา (11 หลัก) | Text (Read-Only) | `STUDENT.student_id` | ดึงรหัสนักศึกษามาแสดง (เฉพาะนักศึกษา) |
| ชื่อ - นามสกุล | Text (Read-Only) | `USER.name` | ดึงชื่อผู้ใช้มาแสดง |
| อีเมลมหาวิทยาลัย (@ubu.ac.th) | Text (Read-Only) | `USER.email` | ดึงอีเมล SSO ของผู้ใช้งาน |
| เบอร์โทรศัพท์ติดต่อ (10 หลัก) | Input (Text) | `STUDENT.phone` | ฟิลด์สำหรับแก้ไขเบอร์โทรศัพท์ (กดบันทึกแล้วอัปเดตลงตาราง) |
| เข้าสู่ระบบครั้งแรก | Text (Datetime) | `USER.first_login` | แสดงวันเวลาที่ใช้งานระบบครั้งแรก |
| เข้าสู่ระบบล่าสุด | Text (Datetime) | `USER.last_login` | แสดงวันเวลาที่เข้าใช้งานระบบล่าสุด |
| สถานะบัญชี / สิทธิ์การยืม | Badge / Text | `USER.blocked`, `USER.block_reason` | แสดงสถานะ "ปกติ" หรือ "ถูกระงับสิทธิ์" พร้อมเหตุผล |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ป้ายบทบาท ("นักศึกษา" / "เจ้าหน้าที่") คำนวณจากสถานะการล็อกอินในตาราง subtype (`STUDENT` / `STAFF`) ไม่ได้เก็บเป็นฟิลด์ข้อความโดด

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `USER`
- `STUDENT`
