# Field Mapping: `page-user-detail.html` (รายละเอียดผู้ใช้งาน)

> **หน้าจอ:** ดูข้อมูลผู้ใช้งานรายบุคคลแบบละเอียด ตรวจสอบที่มาของบทบาทสิทธิ์ และประวัติการเข้าใช้งาน  
> **ไฟล์ต้นทาง:** `pages/page-user-detail.html`  
> **ผู้ใช้งาน:** 👑 ผู้ดูแลระบบ (Admin)  
> **Use Case:** UC-32  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **ข้อมูลส่วนตัวและบัญชี** | | | |
| ชื่อ - นามสกุล | Text | `USER.name` หรือ `ADMIN.name` | ชื่อผู้ใช้งาน |
| อีเมล | Text | `USER.email` หรือ `ADMIN.email` | อีเมลบัญชี |
| รหัสนักศึกษา (ถ้าเป็นนักศึกษา) | Text | `STUDENT.student_id` | รหัส 11 หลัก |
| เบอร์โทรศัพท์ (ถ้าเป็นนักศึกษา) | Text | `STUDENT.phone` | เบอร์โทรศัพท์ 10 หลัก |
| วันเวลาที่เข้าสู่ระบบครั้งแรก | Datetime | `USER.first_login` | วันที่ล็อกอินระบบครั้งแรก |
| วันเวลาที่เข้าสู่ระบบล่าสุด | Datetime | `USER.last_login` หรือ `ADMIN.last_login` | วันที่ใช้งานล่าสุด |
| วันเวลาที่สร้างบัญชี | Datetime | `USER.created_at` หรือ `ADMIN.created_at` | เวลาที่บันทึกบัญชีเข้าระบบ |
| **ข้อมูลบทบาทและสิทธิ์พิเศษ** | | | |
| บทบาทปัจจุบัน | Badge | `STUDENT`, `STAFF`, `ADMIN` | แสดงบทบาทที่ใช้งานจริง |
| ที่มาของบทบาทเจ้าหน้าที่ | Badge / Text | `STAFF.is_override` | ระบุชัดเจนว่าเป็นบทบาทอัตโนมัติจาก UBU SSO (`false`) หรือได้รับแต่งตั้งผ่าน Role Override (`true`) |
| เหตุผลการแต่งตั้งบทบาทพิเศษ | Text | `STAFF.override_reason` | แสดงเหตุผลการแต่งตั้ง (ถ้ามี) |
| ผู้แต่งตั้งบทบาทพิเศษ | Text | `STAFF.assigned_by -> ADMIN.name` | ชื่อแอดมินผู้แต่งตั้งสิทธิ์ |
| วันเวลาที่ได้รับการแต่งตั้ง | Datetime | `STAFF.assigned_at` | เวลาที่แต่งตั้ง |
| **สถานะการระงับสิทธิ์** | | | |
| สถานะการบล็อก | Badge | `USER.blocked` | ปกติ หรือ ถูกระงับสิทธิ์ |
| เหตุผลการระงับสิทธิ์ | Text | `USER.block_reason` | รายละเอียดเหตุผล |
| ผู้สั่งระงับสิทธิ์ | Text | `USER.blocked_by_staff` หรือ `USER.blocked_by_admin` | ผู้สั่งดำเนินการ |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ไม่มีฟิลด์นอกเหนือจากที่ระบุ

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `USER`
- `STUDENT`
- `STAFF`
- `ADMIN`
