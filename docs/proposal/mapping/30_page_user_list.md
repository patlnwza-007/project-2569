# Field Mapping: `page-user-list.html` (จัดการบัญชีและสิทธิ์ผู้ใช้)

> **หน้าจอ:** แสดงรายชื่อผู้ใช้งานทั้งหมด ค้นหา กรอง 3 บทบาท ตรวจสอบสถานะ และลบบัญชี  
> **ไฟล์ต้นทาง:** `pages/page-user-list.html`  
> **ผู้ใช้งาน:** 👑 ผู้ดูแลระบบ (Admin)  
> **Use Case:** UC-32  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **การค้นหาและตัวกรอง** | | | |
| ช่องค้นหาชื่อ อีเมล หรือรหัส (`p_user_list_q`) | Input (Search) | `USER.name`, `USER.email`, `STUDENT.student_id`, `ADMIN.name`, `ADMIN.username` | ค้นหาข้อมูลผู้ใช้ |
| ตัวกรองบทบาทสิทธิ์ (`p_user_list_f-role`) | Filter Select | ตรวจสอบจาก `ADMIN`, `STAFF`, `STUDENT` | กรองตาม 3 บทบาท: นักศึกษา / เจ้าหน้าที่ / ผู้ดูแลระบบ |
| **ตารางรายชื่อผู้ใช้งาน (5 คอลัมน์หลักตาม UC-32)** | | | |
| 1. ข้อมูลผู้ใช้งาน | Text | `USER.name`, `STUDENT.student_id` (สำหรับ นศ.) หรือ `ADMIN.name` | แสดงชื่อ-นามสกุล และรหัสนักศึกษา |
| 2. อีเมล | Text | `USER.email` หรือ `ADMIN.email` | แสดงอีเมลผู้ใช้งาน |
| 3. บทบาทสิทธิ์ (Role) | Badge | พิจารณาจากโครงสร้าง ISA | - มีแถวใน `ADMIN` -> `ผู้ดูแลระบบ`<br>- มีแถวใน `STAFF` -> `เจ้าหน้าที่` (แสดงป้ายพิเศษหาก `is_override = true`)<br>- มีแถวใน `STUDENT` -> `นักศึกษา` |
| 4. สถานะบัญชี | Badge | `USER.blocked`, `USER.block_reason` | แสดง "ปกติ" หรือ "ถูกระงับสิทธิ์" พร้อมเหตุผล |
| 5. การจัดการ (Action Buttons) | Buttons | คำสั่งจัดการ | - `[ ดูรายละเอียด ]` -> ลิงก์ไป `page-user-detail.html?id=X`<br>- `[ ⚙️ กำหนดสิทธิ์ ]` -> ลิงก์ไป `page-role-override.html?id=X`<br>- `[ 🗑️ ลบผู้ใช้ ]` -> ลบแถว `USER` (หรือ `ADMIN`) ออกจากระบบอย่างถาวร |

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ตารางผู้ใช้งานใน mockup ปัจจุบันตัดคอลัมน์ "การยืนยันตัวตน" (Authentication Method) ออกแล้วตามข้อกำหนดของ UC-32
