# Field Mapping: `page-welcome.html` (ยินดีต้อนรับ)

> **หน้าจอ:** หน้า Landing Page ก่อนเข้าสู่ระบบ  
> **ไฟล์ต้นทาง:** `pages/page-welcome.html`  
> **ผู้ใช้งาน:** ผู้ใช้ทั่วไป (Public)  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| โลโก้และข้อความต้อนรับ | Text / Graphic | *ไม่มีใน ERD* | ข้อความประชาสัมพันธ์ระบบยืม-คืนพัสดุออนไลน์ |
| ปุ่ม "เข้าสู่ระบบ (Sign In)" | Button | *ไม่มีใน ERD* | ปุ่มนำทางไปยังหน้า `page-login.html` |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- หน้านี้เป็นหน้า Landing Page ประชาสัมพันธ์ระบบ ไม่มีฟิลด์ที่ดึงหรือบันทึกลงฐานข้อมูลโดยตรง
