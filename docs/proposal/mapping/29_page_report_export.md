# Field Mapping: `page-report-export.html` (ส่งออกรายงาน)

> **หน้าจอ:** ส่งออกรายงานสรุปการดำเนินงานระบบในรูปแบบ PDF หรือ CSV  
> **ไฟล์ต้นทาง:** `pages/page-report-export.html`  
> **ผู้ใช้งาน:** 👷 เจ้าหน้าที่ (Staff)  
> **Use Case:** UC-30  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **ตัวเลือกประเภทรายงานที่ต้องการส่งออก** | | | |
| ตัวเลือกรายงาน (PDF / CSV) | Radio Button | *พารามิเตอร์การประมวลผล* | เลือกรุปแบบรายงานที่ต้องการสร้าง |
| วันที่เริ่มต้น (`from`) | Input (Date) | *พารามิเตอร์การประมวลผล* | กรองข้อมูลตั้งแต่วันที่ระบุ |
| วันที่สิ้นสุด (`to`) | Input (Date) | *พารามิเตอร์การประมวลผล* | กรองข้อมูลถึงวันที่ระบุ |
| **แหล่งข้อมูลที่ดึงมาประมวลผลรายงานแต่ละประเภท** | | | |
| รายงานการยืม-คืนพัสดุ (PDF) | Report Output | `BORROW_REQUEST`, `BORROW_ITEM`, `ITEM`, `USER`, `STUDENT` | สรุปประวัติการยืม-คืนตามช่วงเวลา |
| รายงานพัสดุคงคลังและสถานะ (CSV / PDF) | Report Output | `ITEM`, `MATERIAL`, `DURABLE_MATERIAL`, `EQUIPMENT` | ส่งออกสต็อกคงเหลือและสถานะพัสดุทั้งหมด |
| รายงานค่าปรับและยอดชดใช้ (PDF) | Report Output | `RETURN_REQUEST`, `RETURN_ITEM`, `USER` | สรุปรายได้จากค่าปรับและการชดใช้สิ่งของสูญหาย |
| รายงานการแจ้งซ่อมและความเสียหาย (PDF) | Report Output | `DAMAGE_REPORT`, `EQUIPMENT`, `ITEM` | สรุปประวัติอุปกรณ์ชำรุดและการซ่อมบำรุง |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
1. **ตัวกรองช่วงเวลา (`p_report_export_from`, `p_report_export_to`):** เป็นพารามิเตอร์ส่งไปยัง View เพื่อ Query ข้อมูล ไม่ได้บันทึกลงตาราง
