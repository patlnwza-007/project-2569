# Field Mapping: `page-item-delete.html` (ลบวัสดุออกจากระบบ)

> **หน้าจอ:** ยืนยันการลบวัสดุสิ้นเปลืองหรือสิ่งของที่ไม่ได้ใช้งานออกจากฐานข้อมูล  
> **ไฟล์ต้นทาง:** `pages/page-item-delete.html`  
> **ผู้ใช้งาน:** 👷 เจ้าหน้าที่ (Staff)  
> **Use Case:** UC-22  
> **ตาราง ERD อ้างอิง:** [00_erd_reference.md](./00_erd_reference.md)

---

## 1. รายการฟิลด์และองค์ประกอบบนหน้าจอ

| ฟิลด์ / องค์ประกอบบนหน้าจอ | ประเภท UI | ตาราง.คอลัมน์ (ERD) | คำอธิบาย / ตรรกะการดึงข้อมูล |
|---|---|---|---|
| **ข้อมูลสิ่งของที่จะลบ (แสดงเพื่อยืนยัน)** | | | |
| รหัสสิ่งของ | Text | `ITEM.id` | รหัส ID พัสดุ |
| ชื่อสิ่งของ | Text | `ITEM.name` | ชื่อสิ่งของที่จะลบ |
| ประเภทสิ่งของ | Badge | `ITEM.item_type` | `MATERIAL` (อนุญาตให้ลบได้โดยตรงหากไม่มีประวัติยืม) |
| จำนวนคงเหลือในคลัง | Text | `MATERIAL.qty_available`, `MATERIAL.qty_total` | ตรวจสอบสต็อกปัจจุบัน |
| **การดำเนินการลบ** | | | |
| ปุ่มยืนยันการลบถาวร `[ ยืนยันลบข้อมูล ]` | Button | คำสั่ง DELETE | ลบแถวใน `MATERIAL` และ `ITEM` ออกจากฐานข้อมูล |

---

## 2. ฟิลด์บนหน้าจอที่ไม่ถูกเก็บใน ERD (หรือเป็นสถานะชั่วคราวบน UI)
- ข้อความเตือนความปลอดภัย (Confirmation Modal): แจ้งเตือนว่าการลบจะมีผลถาวร

---

## 3. ตาราง ERD ที่เกี่ยวข้อง
- `ITEM`
- `MATERIAL`
