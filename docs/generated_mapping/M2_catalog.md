## 2. หน้ารายการ (UC-01, UC-02)

### การ์ด 1 ใบ = อะไร
- **ครุภัณฑ์:** 1 การ์ด = 1 ชิ้น (1 แถว `ITEM` + `EQUIPMENT` ตาม asset_tag) — ตรงกับ ERD อยู่แล้ว ไม่ต้องรวมกลุ่ม
- **วัสดุคงทน / วัสดุสิ้นเปลือง:** 1 การ์ด = 1 ชนิดสิ่งของ แสดงจำนวนคงเหลือรวม

### Field → Model
| บนจอ | Model.field | หมายเหตุ |
|---|---|---|
| รูป | `Item.image` | ไม่มีรูป → emoji ตามประเภท (📽️ ครุภัณฑ์ / 🔌 วัสดุคงทน / 📦 วัสดุสิ้นเปลือง) แบบ mockup |
| ป้ายประเภท | `Item.item_type` | |
| ชื่อ | `Item.name` | |
| รหัสครุภัณฑ์ | `Equipment.asset_tag` | เฉพาะครุภัณฑ์ |
| ที่ตั้ง / หน่วยนับ / ราคาจัดซื้อ | `Item.location` / `unit` / `purchase_price` | ราคาแสดงในมุมมอง List (UC-01 ข้อ 3) |
| คงเหลือ / ทั้งหมด | `Material` / `DurableMaterial` `.qty_available` / `.qty_total` | |
| ยืมได้สูงสุด / ค่าปรับต่อวัน | `.max_borrow_days` / `.fine_rate_per_day` | วัสดุคงทน + ครุภัณฑ์ |
| สถานะ (จุดสี) | คำนวณ (ด้านล่าง) | เขียว พร้อมให้ยืม · แดง ถูกยืมหมด (จองคิวได้) · เทา ไม่พร้อมใช้งาน |
| ดาวเฉลี่ย + จำนวนรีวิว | `AVG/COUNT(Review.rating)` ผ่าน `BorrowItem.item` | |
| ปุ่มตะกร้าในหัวหน้า + จำนวน | `SUM(CartItem.qty)` | ลิงก์ไปหน้าตะกร้า (M3) |

### สถานะความพร้อม (ใช้ทั้งตัวกรองและจุดสี)
| ตัวกรอง (`status=`) | วัสดุ / วัสดุคงทน | ครุภัณฑ์ |
|---|---|---|
| `available` พร้อมให้ยืม | `base_status=AVAILABLE` และ `qty_available > 0` | `base_status=AVAILABLE` และ `Equipment.status=AVAILABLE` |
| `empty` ถูกยืมหมด | `base_status=AVAILABLE` และ `qty_available = 0` | `Equipment.status` = `BORROWED` / `RETURN_PENDING` |
| `unavailable` ไม่พร้อมใช้งาน | `base_status=DAMAGED` | `Equipment.status` = `DAMAGED` / `MAINTENANCE` หรือ `base_status=DAMAGED` |

### ค้นหา / กรอง / เรียง / มุมมอง (ทุกอย่างอยู่ใน query string → แชร์ลิงก์ได้, ปุ่ม back ใช้ได้)
| ตัวควบคุม | Query | ค่า |
|---|---|---|
| ค้นหา | `q` | ค้นใน `Item.name` และ `Equipment.asset_tag` (ไม่สนตัวพิมพ์เล็ก/ใหญ่) |
| ประเภท | `type` | `MATERIAL` / `DURABLE_MATERIAL` / `EQUIPMENT` (ข้อ 2) |
| สถานะ | `status` | ตามตารางข้างบน |
| เรียง | `sort` | `qty-desc` (ค่าเริ่มต้น) · `qty-asc` · `name-asc` · `days-desc` ตาม mockup (ครุภัณฑ์นับเป็น 1 ถ้าว่าง, 0 ถ้าไม่ว่าง) |
| หน้า | `page` | ข้อ 6 |

## 5. ต้องตัดสินใจ

1. **มุมมอง 3 แบบ (Grid / Compact / List)** — UC-01 ข้อ 3 กำหนดไว้ และ JS ใน mockup มีโค้ดรองรับ แต่ **ไม่มีปุ่มสลับมุมมองบนหน้า mockup**
   - **แนะนำ:** ทำครบ 3 แบบ พร้อมปุ่มสลับ 3 ปุ่มข้างตัวนับผลลัพธ์ (ตาม UC)
2. **ตัวกรองประเภท** — UC-02 ระบุ `?type=` และ mapping มี "ตัวกรองประเภทพัสดุ" แต่ mockup แสดงปุ่มทางลัดแค่ "ทั้งหมด / พร้อมให้ยืม" (ปุ่มประเภทมีใน JS แต่ไม่มีบนจอ)
   - **แนะนำ:** เพิ่มปุ่มทางลัด ครุภัณฑ์ / วัสดุคงทน / วัสดุสิ้นเปลือง ต่อจาก 2 ปุ่มเดิม
3. **ของที่ไม่แสดงให้นักศึกษาเห็น**
   - **แนะนำ:** ซ่อนจากรายการ: `base_status` = `INACTIVE` / `RETIRED` และครุภัณฑ์ `status` = `RETIRED` / `LOST` · เปิดหน้ารายละเอียดของสิ่งเหล่านี้ → "ไม่พบสิ่งของนี้" · ของชำรุด/ส่งซ่อม **ยังแสดง** (จุดเทา กดยืมไม่ได้)
4. **ปุ่ม "ใส่ตะกร้า" / "จองคิว"** — เป็นงานของ UC-05 / UC-10 ใน M3 (มี popup เลือกจำนวนแบบ Shopee)
   - **แนะนำ:** M2 แสดงปุ่มตามสถานะถูกต้อง (ว่าง → ใส่ตะกร้า, ถูกยืมหมด → จองคิว, ชำรุด → ไม่มีปุ่ม) แต่ **กดได้เมื่อทำ M3 เสร็จ** (ระหว่างนี้ปุ่มเป็นสีจาง + ข้อความ "เปิดใช้เร็ว ๆ นี้") · popup เลือกจำนวนทำใน M3
5. **เจ้าหน้าที่เปิดหน้ารายละเอียดได้ไหม** — UC-37 actor มีเจ้าหน้าที่ และ mapping หน้า detail ระบุทั้ง 2 บทบาท แต่หน้ารายการเป็นของนักศึกษา (เจ้าหน้าที่มีหน้าจัดการคลังของตัวเองใน M7)
   - **แนะนำ:** หน้ารายการ = นักศึกษาเท่านั้น · หน้ารายละเอียด = นักศึกษา + เจ้าหน้าที่ (เจ้าหน้าที่ไม่เห็นปุ่มตะกร้า/คิว, ปุ่ม "กลับ" ไปหน้าจัดการคลัง)
6. **แบ่งหน้า** — UC-01 ข้อ 4 บอก pagination/scroll แต่ mockup ไม่มี
   - **แนะนำ:** หน้าละ 24 รายการ มีปุ่ม ก่อนหน้า / ถัดไป ใต้รายการ
7. **ที่ตั้งปัจจุบันของครุภัณฑ์ที่ถูกยืมอยู่** (`BorrowItem.current_location` ที่ผู้ยืมแจ้งย้าย เช่น "หอพัก...") — mapping ให้แสดงในหน้ารายละเอียด แต่เป็นข้อมูลของนักศึกษาคนอื่น
   - **แนะนำ:** แสดงให้ **เจ้าหน้าที่เท่านั้น** · นักศึกษาเห็นแค่ "กำลังถูกยืม"
8. **ชื่อผู้รีวิว** — mapping ให้แสดง `USER.name` เต็ม
   - **แนะนำ:** แสดงชื่อเต็มตาม mapping · ถ้าอยากเป็นส่วนตัวกว่า เลือกแบบย่อได้ เช่น "สมชาย ใ."
