## §B บล็อกรายหน้า

รูปแบบ: **วัตถุประสงค์** (Post-condition) · **ความสามารถ** (Basic Flow) · **Empty/Error** (Alternative Flow) · **กฎ** (Business Rules) · **นำทางเข้า-ออก**

### Welcome
- **วัตถุประสงค์:** จุดเริ่มต้นก่อนเข้าสู่ระบบ
- **ความสามารถ:** ปุ่ม "เข้าสู่ระบบด้วย Google/UBU SSO" เท่านั้น
- **Empty/Error:** ไม่มี (ไม่มีฟอร์ม/ข้อมูลก่อนล็อกอิน)
- **กฎ:** ห้ามแสดงข้อมูลใด ๆ ก่อนล็อกอิน
- **นำทางเข้า-ออก:** เข้า: จุดเริ่มต้นแอป (ยังไม่ล็อกอิน) / ออก: กด "เข้าสู่ระบบ" → Login

### Login (UC-16)
- **วัตถุประสงค์:** จำลองการยืนยันตัวตนผ่าน UBU Single Sign-On
- **ความสามารถ:** เลือกจำลองผลลัพธ์ล็อกอินเป็นแต่ละ role (นักศึกษา/เจ้าหน้าที่/override) เพื่อ demo
- **Empty/Error:** ยืนยันตัวตนไม่สำเร็จ / บัญชีถูกระงับสิทธิ์ (Block) → ข้อความปฏิเสธการเข้าสู่ระบบ
- **กฎ:** รับบทบาทเริ่มต้นจาก SSO ก่อนเสมอ แล้วจึงเช็ค Role Override ทับ (UC-34/35)
- **นำทางเข้า-ออก:** เข้า: Welcome / ออก: ล็อกอินสำเร็จ → RequestList (student) / StaffDashboard (staff) / UserList (admin)

### RequestList (UC-10)
- **วัตถุประสงค์:** นักศึกษาเห็นสถานะคำขอยืมทั้งหมดของตนเอง
- **ความสามารถ:** รายการคำขอยืม + ป้ายสถานะ (รออนุมัติ/ปฏิเสธแล้ว/อนุมัติแล้ว-รอรับของ/หมดอายุ/กำลังยืม/รอยืนยันการคืน/คืนสำเร็จ/เบิกสำเร็จ) · ยกเลิกคำขอ (UC-07, เฉพาะสถานะ "รออนุมัติ")
- **Empty/Error:** "ยังไม่มีรายการยืม"
- **กฎ:** ยกเลิกได้เฉพาะสถานะ "รออนุมัติ"
- **นำทางเข้า-ออก:** เข้า: Login สำเร็จ / เมนูหน้าหลัก จากทุกหน้าของ Student / ออก: ไป Profile, ItemList, QueueList, Cart, ConfirmPickup, NotifyReturn, History, Suggestion

### Profile (UC-14)
- **วัตถุประสงค์:** จัดการข้อมูลติดต่อของตนเอง
- **ความสามารถ:** แก้ไขเบอร์โทรศัพท์ · อ่านอย่างเดียว: วันที่เข้าสู่ระบบครั้งแรก/ล่าสุด
- **Empty/Error:** —
- **กฎ:** ข้อมูลติดต่อต้องครบก่อนส่งคำขอยืมได้ (บังคับใช้ที่ RequestForm/UC-06)
- **นำทางเข้า-ออก:** เข้า: เมนูโปรไฟล์ (RequestList) หรือถูกบังคับมาจาก RequestForm เมื่อข้อมูลไม่ครบ / ออก: บันทึกสำเร็จ → RequestList (ปกติ) หรือกลับไป Cart (ถ้ามาจาก RequestForm)

### ItemList (UC-01, extend UC-02)
- **วัตถุประสงค์:** ค้นหา/เลือกดูสิ่งของที่ยืมได้
- **ความสามารถ:** แสดงรูป/ชื่อ/หมวดหมู่/สถานะ/จำนวนคงเหลือ · ช่องค้นหา + ตัวกรองหมวดหมู่/ประเภท/สถานะ (UC-02) · เพิ่มลงตะกร้าจากรายการ
- **Empty/Error:** "ยังไม่มีรายการสิ่งของ" / "ไม่พบรายการที่ค้นหา"
- **กฎ:** —
- **นำทางเข้า-ออก:** เข้า: เมนูรายการสิ่งของ (RequestList) / ออก: เลือกสิ่งของ → ItemDetail, เพิ่มลงตะกร้า → Cart, กลับ → RequestList

### ItemDetail (UC-03)
- **วัตถุประสงค์:** ดูรายละเอียดสิ่งของก่อนยืม/จองคิว
- **ความสามารถ:** แสดงชื่อ/รูป/จำนวนคงเหลือ/ตำแหน่งชั้นวาง/ข้อมูลคิวรอ · ปุ่ม "เพิ่มลงตะกร้า" (คงเหลือ > 0) หรือ "จองคิว" (คงเหลือ = 0, UC-11)
- **Empty/Error:** สิ่งของถูกลบ/ปลดระวางแล้ว → "ไม่พบสิ่งของนี้"
- **กฎ:** จองคิวได้เฉพาะเมื่อคงเหลือ = 0
- **นำทางเข้า-ออก:** เข้า: ItemList (เลือกสิ่งของ) / ออก: PositionMap (ดูตำแหน่ง), Cart (เพิ่มลงตะกร้า), QueueList (หลังจองคิวสำเร็จ), กลับ → ItemList

### PositionMap (UC-04)
- **วัตถุประสงค์:** ช่วยหาตำแหน่งจัดเก็บจริงของสิ่งของ
- **ความสามารถ:** จัดกลุ่มตามตู้/ชั้นวาง พร้อมสิ่งของในแต่ละตำแหน่ง
- **Empty/Error:** "ยังไม่มีข้อมูลตำแหน่งจัดเก็บ"
- **กฎ:** —
- **นำทางเข้า-ออก:** เข้า: ItemDetail / ออก: กลับ → ItemDetail

### QueueList (UC-11)
- **วัตถุประสงค์:** ติดตามลำดับคิวของตนเอง
- **ความสามารถ:** ลำดับคิวต่อสิ่งของแต่ละชิ้น + ปุ่ม "ออกจากคิว"
- **Empty/Error:** ไม่มี note เพิ่มเติมใน state diagram (ดูพฤติกรรมอัตโนมัติใน §C — แจ้งเตือนถึงคิว)
- **กฎ:** การจองคิวใหม่ทำที่ปุ่มบนหน้า ItemDetail เท่านั้น ไม่ใช่หน้านี้
- **นำทางเข้า-ออก:** เข้า: เมนู "คิวของฉัน" (RequestList) หรือต่อเนื่องจาก ItemDetail หลังจองคิวสำเร็จ / ออก: กลับ → RequestList

### Cart (UC-05)
- **วัตถุประสงค์:** รวบรวมรายการก่อนส่งคำขอยืม
- **ความสามารถ:** รายการสิ่งของ + ช่องแก้ไขจำนวน + ปุ่มลบรายการ
- **Empty/Error:** จำนวนที่ต้องการเกินจำนวนคงเหลือจริง → แจ้งเตือน ไม่ให้เพิ่ม/แก้เกิน
- **กฎ:** —
- **นำทางเข้า-ออก:** เข้า: ItemDetail/ItemList (เพิ่มลงตะกร้า), เมนูตะกร้า (RequestList), กลับจาก Profile (ข้อมูลครบแล้ว) / ออก: RequestForm (ยืนยันส่งคำขอ, include UC-05), ItemList (เลือกซื้อเพิ่ม), กลับ → RequestList

### RequestForm (UC-06)
- **วัตถุประสงค์:** ยืนยันส่งคำขอยืม
- **ความสามารถ:** ฟิลด์เหตุผลการยืม (บังคับ), วันที่ต้องการใช้งาน (บังคับเฉพาะเมื่อตะกร้ามีครุภัณฑ์อย่างน้อย 1 ชิ้น)

- **กฎ:** มีผลเหนือกว่าบทบาทเริ่มต้นจาก UBU SSO เสมอ จนกว่าแอดมินจะยกเลิก
- **นำทางเข้า-ออก:** เข้า: UserDetail (กด "กำหนดบทบาทเฉพาะบุคคล") / ออก: บันทึกสำเร็จ/ยกเลิก Override/กลับ → UserDetail, เลือกกำหนดแบบกลุ่มผ่านไฟล์แทน → RoleOverrideBulk (extend UC-35)

### RoleOverrideBulk (extend UC-35)
- **วัตถุประสงค์:** กำหนดบทบาทหลายบัญชีพร้อมกัน
- **ความสามารถ:** ปุ่มดาวน์โหลด template + อัปโหลดไฟล์ CSV (อีเมล + บทบาท)
- **Empty/Error:** รูปแบบผิด/มีแถวข้อมูลผิดพลาด → แจ้งรายการที่ผิด
- **กฎ:** —
- **นำทางเข้า-ออก:** เข้า: RoleOverride (เลือกกำหนดแบบกลุ่มผ่านไฟล์) / ออก: นำเข้าสำเร็จ/กลับ → RoleOverride

### PersonnelExport (UC-36)
- **วัตถุประสงค์:** ส่งออกรายชื่อบุคลากรทั้งหมด
- **ความสามารถ:** ปุ่ม "ส่งออกไฟล์" เดียว → ได้ไฟล์ CSV รายชื่อบุคลากรทั้งหมดพร้อมบทบาทปัจจุบัน
- **Empty/Error:** —
- **กฎ:** —
- **นำทางเข้า-ออก:** เข้า: เมนู "ส่งออกรายชื่อบุคลากร" (UserList) / ออก: ดาวน์โหลดสำเร็จ/กลับ → UserList
